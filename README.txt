日次売上サマリ ― 使い方

■ これは何をするものですか
3店舗（店A・店B・店C）の売上CSVを読み込んで、
・3店舗の合計売上
・前の営業日との比較
をまとめたファイル（Excel形式）を自動で作るツールです。

■ 使い方
1. 各店舗から届いた最新のCSVファイルを、「data」フォルダの中に上書きで置いてください。
   届いたファイルの名前が指定と違う場合は、以下の名前に変更してから置いてください
   （店A_売上.csv / 店B_売上.csv / 店C_売上.csv）。
2. 「日次売上サマリ.exe」をダブルクリックしてください。
   ※このexeファイルは「data」「output」フォルダと同じ場所に置いたままにしてください。
   　デスクトップなど別の場所に移動すると動かなくなります。
3. 少し待つと処理が終わり、黒い画面は自動で閉じます。
   もしエラーメッセージが表示されたまま画面が閉じない場合は、処理が失敗しています。
   メッセージの内容を控えてご連絡ください（Enterキーを押すと画面は閉じます）。
4. 「output」フォルダの中に、「日次売上サマリ_（日付）.xlsx」という名前のファイルができています。
   一番新しい日付のものを開いて、印刷してお使いください。
   ※このファイルが新しくできていない場合も、処理が失敗しています。ご連絡ください。

■ 実行時に警告が出た場合
Windowsが「WindowsによってPCが保護されました」という青い画面を表示することがあります。
これはこのツールが一般に配布されているアプリではないために出る、通常の注意書きです。
「詳細情報」をクリックし、「実行」ボタンを押せば起動します。
このツールはお使いのパソコンの中だけで動作し、インターネットにデータを送ることはありません。

■ レポートの見方
・店舗の欄に「定休日」と書かれている場合は、その日その店舗が休業だったことを意味します
　（現時点では店Aの毎週水曜のみ該当）。売上が0円だったという意味ではありません。
・店舗の欄に「データ未着」と書かれている場合は、定休日ではないのにその店舗のデータが
　届いていない状態です。単純な送り忘れの可能性があるので、レポート上部に警告が
　表示されます。その店舗に確認をお願いします。
・「前営業日合計」「差額」「増減率」は、定休日をはさんでいてもおかしな比較にならないよう、
　各店舗ごとに直前で実際に営業していた日と比べて計算しています。

■ 来年、店舗が増える場合について
新しい店舗の分は自動では追加されません。データの形式が分かり次第、
ツール側に設定を1つ追加する必要があります。店舗が増えるタイミングでご連絡ください。

■ うまく動かないときは
・「data」フォルダのファイル名が指定の通りか確認してください。
・CSVの中身（列の並びや文字コード）が今までと大きく変わった場合は、動かなくなることがあります。
　その場合はご連絡ください。
